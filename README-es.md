## Instalación

Instalar y verificar:

```sh
dsh plugin --profile <profile> add dsh-travel-recon
dsh --profile <profile> --dump-config | grep dsh-travel-recon
```

Desinstalar:

```sh
dsh plugin --profile <profile> remove dsh-travel-recon
```


### Canales de instalación

npm es el canal recomendado; los demás sirven para fijar versión u offline.

- **npm (recomendado):** `dsh plugin --profile <profile> add dsh-travel-recon`
- **canal git:** `dsh plugin --profile <profile> add github:PerryLink/dsh-travel-recon`
- **tarball:** `pnpm pack` then `dsh plugin --profile <profile> add ./dsh-travel-recon-<version>.tgz`
- **tienda 1024:** `npm i -g dsh1024` then `dsh1024 plugin --profile <profile> add dsh-travel-recon`

## Qué hace

Ingesta de pedidos/facturas/tarjetas de viaje, deduplicación, conciliación triple y registro. Se ejecuta localmente en DeepSeek Harness. La tabla siguiente es la superficie exacta de herramientas; los ejemplos usan la interfaz real.

La entrada y la salida permanecen locales; no se sube nada.

## Herramientas

Los nombres de herramientas son la API estable; las descripciones están localizadas.

| Herramienta | Propósito | Riesgo |
|---|---|---|
| `travel.ingest` | Ingerir filas de pedido/factura/tarjeta de viaje | R1 local write |
| `travel.match` | Conciliación de tres vías pedido/factura/tarjeta | R0 |
| `travel.duplicate_check` | Detectar facturas/tarjetas duplicadas por viaje | R0 |
| `travel.policy_check` | Comprobación de política de solo lectura sobre importe máximo y presencia de factura | R0 |
| `travel.export` | Exportar el xlsx del libro de conciliación | R1 local write |

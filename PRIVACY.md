# Privacy

`dsh-travel-recon` is a local, public/synthetic alpha project.

- It does **not** collect telemetry, analytics, or usage data.
- It does **not** upload files, call a model, or call a network service unless a tool in the README explicitly says so.
- Its fixtures are public/synthetic; no customer data is included.
- The package writes only to the local paths documented in its README and `DSH_*` environment variables.
- npm/GitHub/Gitee/GitCode process download and repository metadata under their own privacy policies; that is outside this package.

# Security policy

This repository is an **alpha, public/synthetic demo** of a DeepSeek Harness plugin. It is not GA and has no customer evidence.

- Do **not** paste real invoices, contracts, profiles, bank statements, customer documents, logs, tokens or PII into an issue or PR.
- Report security issues through **GitHub private security advisories** for this repository, not a public issue.
- The plugin is local-first; network use is limited to the documented registry/lookup paths in its README. If you find an undeclared network call, treat it as a security issue.
- No secrets belong in the repository; use environment variables or the host's credential services.

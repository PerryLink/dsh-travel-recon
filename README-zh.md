## 安装

安装并验证：

```sh
dsh plugin --profile <profile> add dsh-travel-recon
dsh --profile <profile> --dump-config | grep dsh-travel-recon
```

卸载：

```sh
dsh plugin --profile <profile> remove dsh-travel-recon
```


### 安装通道

推荐 npm；其他通道用于固定版本或离线。

- **npm（推荐）:** `dsh plugin --profile <profile> add dsh-travel-recon`
- **git 通道:** `dsh plugin --profile <profile> add github:PerryLink/dsh-travel-recon`
- **tarball:** `pnpm pack` then `dsh plugin --profile <profile> add ./dsh-travel-recon-<version>.tgz`
- **1024 商店:** `npm i -g dsh1024` then `dsh1024 plugin --profile <profile> add dsh-travel-recon`

## 它做什么

差旅订单/发票/卡流水对账、去重与只读政策检查。 在 DeepSeek Harness 本地运行；下表就是实际工具面，示例使用真实命令面。

输入和输出都留在本地，不上传。

## 工具

工具名是稳定 API；说明已本地化。

| 工具 | 用途 | 风险 |
|---|---|---|
| `travel.ingest` | 导入差旅订单/发票/卡账单行 | R1 local write |
| `travel.match` | 对订单/发票/卡账单执行三单匹配 | R0 |
| `travel.duplicate_check` | 按行程检测重复的发票/卡账单 | R0 |
| `travel.policy_check` | 只读的金额上限与发票存在性策略检查 | R0 |
| `travel.export` | 导出对账台账 xlsx | R1 local write |

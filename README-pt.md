## Instalação

Instalar e verificar:

```sh
dsh plugin --profile <profile> add dsh-travel-recon
dsh --profile <profile> --dump-config | grep dsh-travel-recon
```

Desinstalar:

```sh
dsh plugin --profile <profile> remove dsh-travel-recon
```


### Canais de instalação

npm é o canal recomendado; os demais servem para fixar versão ou offline.

- **npm (recomendado):** `dsh plugin --profile <profile> add dsh-travel-recon`
- **canal git:** `dsh plugin --profile <profile> add github:PerryLink/dsh-travel-recon`
- **tarball:** `pnpm pack` then `dsh plugin --profile <profile> add ./dsh-travel-recon-<version>.tgz`
- **loja 1024:** `npm i -g dsh1024` then `dsh1024 plugin --profile <profile> add dsh-travel-recon`

## O que faz

Ingestão de pedidos/faturas/cartões de viagem, deduplicação, conciliação tripla e registro. Executa localmente no DeepSeek Harness. A tabela abaixo é a superfície exata de ferramentas; os exemplos usam a interface real.

Entrada e saída permanecem locais; nada é enviado.

## Ferramentas

Os nomes das ferramentas são a API estável; as descrições estão localizadas.

| Ferramenta | Finalidade | Risco |
|---|---|---|
| `travel.ingest` | Ingere linhas de pedido/fatura/cartão de viagem | R1 local write |
| `travel.match` | Conferência de três vias pedido/fatura/cartão | R0 |
| `travel.duplicate_check` | Detecta faturas/cartões duplicados por viagem | R0 |
| `travel.policy_check` | Verificação de política somente leitura de valor máximo e presença de fatura | R0 |
| `travel.export` | Exporta o xlsx do registro de conciliação | R1 local write |
